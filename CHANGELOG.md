# CHANGELOG
All released versions changes will be tracked and documented in this file.

## [0.2](https://github.com/Dtar380/VideoService/releases/tag/0.2.0) - 3rd January 2025
This release is characterised by a complete rework of the codebase.

### Added
- Playlist support
- View count
- Simpler database management
- Security
- Better errors

### Removed
- Search Engine

## [0.1](https://github.com/Dtar380/VideoService/releases/tag/0.1.2) - 31st July 2024
This is the first release of the VideoService library. It packages all 0.1.0, 0.1.1 and 0.1.2 into one as they where released the same day.

### Added
- Video Class
- Videos Class
- VideoService Class
- Attempt of Search Engine (Deprecated)
